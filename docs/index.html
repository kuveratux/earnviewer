        ランキングでの表示名

        ランキングタブの一覧で、あなたの行に表示する名前です（この端末だけに保存）。空欄なら「自分」と表示します。

        計算の設定

        TEEP資格があるときはチェックを入れて、TEEP を選びます。新EARN Tier の年利に TEEP の倍率を掛けて計算します（旧EARN Tier の期間には掛けません）。チェックしていないときは 100% で計算します。
